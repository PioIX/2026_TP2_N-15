# Mates Online

Mates Online es una página web de e-commerce dedicada a la venta de mates artesanales y accesorios relacionados con la tradición argentina.

El sitio cuenta con diferentes secciones:
- Inicio
- Productos
- Reseñas de clientes
- Formulario de contacto

Fue desarrollada utilizando HTML5, CSS3, Flexbox, Grid y diseño responsive.
